# نتیجه بررسی نسخه ۲۰۲۶-۰۸-۲۸

آخرین اصلاح واچ: ۱۱۳ تست unittest موفق. رفتار replay تاریخی عمداً طبق درخواست جدید به latest-closed-only تغییر کرد و تست مربوطه به قرارداد جدید به‌روز شد؛ آستانه‌های تریگر یا قواعد گرید تغییر نکردند. جزئیات در WATCH_CLOSE_TEST_FA.md.

آخرین نسخه زمان تأییدشده: **۱۰۵/۱۰۵ تست اصلی، ۱۴/۱۴ تست قوانین و compileall موفق**. این بار علاوه بر تست آفلاین، تیک و M5/M15/H1 واقعی EURUSD و XAUUSD از MT5 همین رایانه خوانده و تبدیل خام UTC+3 به UTC و تهران تأیید شد. هیچ تحلیل AI، پیام واقعی تلگرام یا سفارشی اجرا نشد. جزئیات و دستور نصب معتبر در INSTALL_TIME_VERIFIED_FA.md است؛ گزارش‌های قدیمی پایین صرفاً سابقه‌اند.

به‌روزرسانی اصلاح ساعت بروکر: ۱۰۱/۱۰۱ تست unittest و ۱۴/۱۴ تست مستقل قوانین موفق شدند؛ compileall موفق بود. سناریوهای جدید شامل ساعت بروکر جلوتر/عقب‌تر از ویندوز، توقف جریان قیمت، الزام تیک تازه برای شروع، حذف کندل صفر و مانیتور واچ با اختلاف ساعت هستند. نتایج قدیمی پایین برای سابقه حفظ شده‌اند.

محیط: Windows، Python 3.12.5، python-telegram-bot 21.6، openai 1.57.4.

| بررسی | نتیجه |
|---|---|
| unittest discover | ۸۷ از ۸۷ موفق، دو اجرای متوالی پس از اصلاحات سرویس |
| تست مستقل رگرسیون قوانین | ۱۴ از ۱۴ موفق |
| کامپایل ماژول‌های پروژه | موفق |
| تست اختیاری API بدون --live-api | بدون تماس API خارج می‌شود |

۳۴ سناریوی یکپارچه در `tests/test_runtime_flow.py` شامل تریگر اتمیک، عدم تریگر با سایه، کندل باز، برابری سطح، ابطال، انقضا، بازیابی، صف تحلیل و پیام، retry، داده حساب، اعتبارسنجی پیش از ثبت، ثبت معتبر و rollback هستند. تست‌های ساختاری، ایمنی و بازتولید باگ‌های بازبینی نیز در پوشه tests قرار دارند.

در اجرای مستقل تست قدیمی قوانین، fixture معامله گرید A ریسک ۱٪ داشت، درحالی‌که سقف پیش‌فرض پروژه ۰٫۵٪ است؛ fixture به ۰٫۵٪ اصلاح شد، نه قانون یا سقف ریسک تولید. خطای عمدی نماد BAD و حساب قطع‌شده در خروجی تست‌ها انتظار می‌رود و خودِ سناریوی ایمنی است.

آزمون اولیه test_manual به‌علت نبود کلید پیش از تماس شبکه متوقف شد؛ سپس اجرای واقعی آن نیازمند گزینه صریح --live-api شد. هیچ تماس زنده API، پیام واقعی تلگرام یا معامله واقعی در این بررسی انجام نشده است. کلیدها و دیتابیس اصلی کاربر تغییر نکرده‌اند.

موفقیت تست آفلاین تضمین رفتار همه بروکرها، شبکه، Wine یا سودآوری نیست. پیش از استفاده واقعی، معیار پذیرش دمو در RELEASE_FA.md را اجرا کنید.
