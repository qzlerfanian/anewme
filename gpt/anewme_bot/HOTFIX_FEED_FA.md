# اصلاح تشخیص وضعیت بازار — ۲۰۲۶-۰۸-۲۸

تغییر تولید فقط در broker/mt5_broker.py است. منطق واچ، گریدها، تحلیل و محاسبه کندل تغییر نکرده است.

مقایسه با فایل اصلی نشان داد شرط قدیمی فقط age < 300 بود؛ نسخه اصلاح‌شده شرط 0 <= age < 300 اضافه کرده بود. بنابراین تیک جلوتر از ساعت سیستم که قبلاً بی‌قید پذیرفته می‌شد، به اشتباه «بازار بسته» معرفی می‌شد. این اختلاف کد تأیید شده، اما بدون زمان واقعی تیک حساب کاربر علت نمونه گزارش‌شده قطعی نیست.

در این اصلاح، قطع اتصال، نماد غیرفعال، تیک مفقود، تیک قدیمی و اختلاف ساعت دیگر به عنوان تعطیلی بازار معرفی نمی‌شوند. دلیل دقیق و زمان UTC سیستم، زمان تیک و اختلاف ثانیه‌ای برای خطاهای زمانی نمایش/ثبت می‌شود. داده قدیمی یا آینده همچنان برای تحلیل پذیرفته نمی‌شود؛ ساعت داده به‌صورت حدسی جابه‌جا نشده است.

برای نصب، ربات را متوقف کنید و فقط broker/mt5_broker.py این بسته را روی همان فایل نسخه اصلاح‌شده قبلی جایگزین کنید. نیازی به تعویض .env یا دیتابیس نیست. یا بسته کامل را در پوشه جدا طبق RELEASE_FA.md نصب کنید. شش تست آفلاین جدید برای این بخش اضافه شده‌اند. اتصال واقعی حساب کاربر آزمایش نشده است.

اگر بعد از نصب پیام اختلاف ساعت یا تیک قدیمی آمد، همان پیام بدون توکن/اطلاعات حساب برای تشخیص لازم است؛ این اصلاح به‌تنهایی خرابی اتصال یا ساعت ویندوز را برطرف نمی‌کند.
